Open-source contributions

All pull requests by shrpawar-alt

NeMo-text-processing is NVIDIA's library of weighted finite-state grammars for text normalization. I write Hindi grammars in pynini using a tagger and verbalizer design, driven by TSV data files, and I answer review from the NeMo maintainers. Hindi TN v3 is merged and v4 is in progress.
